# NexusTech
# 🚀 Nexus Tech — La Transformación Digital

![Nexus Tech Banner](assets/img/banner.png)

## 🌐 Descripción del Proyecto

**Nexus Tech** es una plataforma web editorial enfocada en tecnología, innovación y tendencias digitales.

El proyecto representa la transformación de una revista tecnológica tradicional hacia una experiencia digital moderna, combinando una estética retro tecnológica con una interfaz futurista, accesible y visualmente atractiva.

La idea principal fue crear una plataforma que conecte la nostalgia de la tecnología clásica con la innovación actual, utilizando elementos visuales inspirados en televisores antiguos, dispositivos analógicos, interfaces digitales y la evolución tecnológica a través del tiempo.

# 🎨 Dirección Artística

El diseño de **Nexus Tech** está inspirado en la evolución de la tecnología, mezclando elementos del pasado con una visión futurista.

La identidad visual representa la conexión entre los dispositivos clásicos y las nuevas experiencias digitales, creando una interfaz donde la tecnología antigua y moderna conviven.

La propuesta estética combina:

📺 Televisores y tecnología retro.
⚙️ Elementos mecánicos e industriales.
💾 Interfaces inspiradas en sistemas antiguos.
🌐 Diseño digital futurista.
🔬 Conceptos visuales relacionados con innovación tecnológica.

### Elementos principales:

* Televisores y dispositivos analógicos como elementos protagonistas.
* Inspiración en la transición tecnológica entre lo clásico y lo moderno.
* Interfaces con referencias a sistemas antiguos.
* Diseño editorial adaptado al entorno digital.
* Contraste entre texturas retro y componentes tecnológicos actuales.

La intención del diseño es transmitir que la tecnología no elimina el pasado, sino que evoluciona a partir de él.

# 🔄 Control de Versiones

El proyecto utiliza Git para mantener un flujo de desarrollo organizado.

## 🌱 Estructura de ramas

```text
main
 |
develop
 |
features
```

## Flujo utilizado:

1. Desarrollo de nuevas funcionalidades en la rama `develop`.
2. Pruebas y validación local.
3. Creación de commits descriptivos.
4. Integración de cambios hacia `main`.
5. Sincronización con repositorio remoto.

Ejemplos de commits:

```bash
feat: add Nexus logo and articles section

style: implement visual identity and article cards

assets: sync project images
```
